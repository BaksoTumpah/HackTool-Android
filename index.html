Masukkan IP ESP32-C3 (atau pakai Cari otomatis), lalu klik Hubungkan…
Tombol mensimulasikan tekan/lepas tactile switch fisik di board utama lewat WiFi.

🔒 Masukkan Token

Token akses kontrol ESP32-C3 diperlukan sebelum bisa mengirim perintah.

Pengaturan

WiFi AP ESP32-C3

Nama & password hotspot yang dipancarkan ESP32-C3. Restart otomatis setelah disimpan.

Update Firmware (OTA)

Upload file firmware baru (.bin) langsung dari sini — tidak perlu Arduino IDE.

Kalau upload dari sini gagal (biasanya karena app dibuka lewat link https, browser memblokir akses ke perangkat http lokal), buka http://<ip-esp32>/update langsung di browser HP/laptop yang konek ke WiFi HackTool — form upload yang sama tersedia di sana. Alternatif lain: Arduino IDE → Tools → Port, pilih port jaringan HackTool at 192.168.4.1 (password OTA = token akses saat ini).

Token Akses Kontrol

Token dibutuhkan agar tombol bisa mengontrol device.

Tema Aplikasi

Warna tampilan controller.

Kalibrasi Baterai

Atur tegangan saat baterai kosong (0%) dan penuh (100%).

Waktu Jeda Deep Sleep

ESP32-C3 tidur untuk hemat baterai kalau tidak ada yang terhubung.
